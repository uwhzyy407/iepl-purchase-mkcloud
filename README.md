## 先搞清楚：IEPL 是什么，适合谁

IEPL 全称 International Ethernet Private Line，国际以太网专线。简单说，它是一条从国内机房到海外机房之间的私有物理通道，链路层（L2）直连，数据包从入口到出口不经过公网转发。

它和你日常接触到的几种"加速方案"差别在这里：

- **CN2 GIA**：仍然走公网骨干网，本质是优化过的公网路由。
- **普通 VPN / 机场中转**：路径复杂，多跳公网节点，速度和稳定性波动大。
- **IPLC**：国际私有专线，但接口是 PDH/SDH 传统协议。
- **IEPL**：接口是基于以太网的私有专线，价格通常低于 IPLC，但延迟几乎相当。
- **IXP 上云互联**：通过运营商前置机+优化路由接入，价格最低，适合已有云网络的场景。

如果你的业务对延迟敏感（金融交易、跨境直播、Shopify 后台同步、海外平台账号环境隔离）、同时数据不希望走公网，IEPL 是性价比比较高的中间档选择。同等距离下，IPLC 通常只比 IEPL 低 2~3ms 延迟，但价格高出一截，对绝大多数跨境电商、跨境办公用户来说，IEPL 是更划算的折中。

## 买 IEPL 之前需要先确认的四件事

IEPL 不是付费就能用的消费品，下单前要确认这些前提：

**1. 用途必须合规**

提供 IEPL 的厂商通常会明确禁止用作机场、回国加速、违规翻墙等途径。Mkcloud 的全部专线产品在购买前都会要求实名认证，且入口机器只允许单一省份 IP 连入，省份可在购买后修改。这是为了防止产品被挪用做违规用途。购买前先想清楚你的用途是否符合合规边界。

**2. 入口省份选择**

跨境专线入口只会放行一个省份的 IP。比如广港 IEPL 的入口是腾讯广州八线 BGP，广东用户连接效果最好，全国三网用户也可以连入，但访问端 IP 必须落在所选省份内。选错省份会导致连不上或速度异常。

**3. 流量计费 vs 独享带宽**

- 流量计费（共享带宽峰值）：按上行+下行双向统计，超量后暂停，适合日常使用。
- 独享带宽：保证固定速率（常见 5Mbps~200Mbps 不等），不限流量，适合上传量稳定、要求速率恒定的场景。

很多商家在套餐表里同时提供两种计费方式，价格和 IP 配置完全不同，下单时一定要看清。

**4. 退款政策不通用**

合规专线一般只支持"质量问题退款"，且开通后不支持更换到其他地域（无法从广港 IEPL 改成沪日 IPLC）。如果有质量问题，需要提供具体延迟、丢包、速度数据并走工单流程。所以第一次购买建议从低流量档位试水。

## 选购前的几条核心判断

**不要只看单价**：跨境专线要看同一线路、同一计费方式下不同档位的差价规律。Mkcloud 的规律是：流量翻倍带来的档位差价通常在 30%~50%，而不是翻 2 倍。

**延迟优先 vs 价格优先**：广港 IEPL 端内延迟 1~2ms，是 Mkcloud 全部产品里最低的，但价格只比沪港 IPLC 高 ¥70/月（1TB 档），比沪美低 ¥70/月。如果你的业务对延迟敏感但不一定需要香港出口，这两条线路都值得考虑。

**IXP 不适合所有人**：如果你还没有公有云网络资源，IXP 上云互联专线需要自己再额外买云前置（阿里云/腾讯云/UCloud 等），起步成本反而更高。但如果你已经有云环境，把专线作为云前置通往海外的出口，长期成本会比单独买 IPLC 划算。

**合规边界需要自己评估**：合规专线服务商所有产品都有省级白名单限制，并禁止用作机场、回国专线。如果你的需求恰恰在这条边界上，建议直接绕道而行，不要尝试绕过白名单限制，否则账号有被永久封禁的风险。

## FAQ：几个常见疑问

**Q1：IEPL 真的能稳定访问 Google、Netflix、TikTok 吗？**

合规跨境专线的出口 IP 通常是运营商家宽 / BGP IP，自然具备流媒体平台区域识别能力。从多个独立测评看，Mkcloud 广港 IEPL 默认出口 IP 在 Netflix、Disney+、TikTok、YouTube Premium、Spotify 等平台上识别为香港区，亚马逊 Prime Video 同样识别为 HK 区，能满足日常流媒体区域识别需要。但平台策略随时调整，购买前最好确认自己业务的目标平台。

**Q2：1TB 流量够不够用？**

举例粗算：一个 Shopify 店铺每天同步订单 + 日常后台操作大约消耗 0.5~1GB；TikTok 美区日常刷流 + 自动化任务每日消耗 1~2GB；直播推流每小时约 1~1.5GB。如果只是单店铺后台，1TB 月流量完全够用，多账号矩阵或直播场景建议 2TB 起。

**Q3：退款怎么走？**

Mkcloud 的退款政策只支持质量问题退款，且开通后不支持更换到其他地域。退款需要提交工单，并提供具体延迟数据、丢包率、速度截图证明是产品服务质量问题，官方审核通过后会处理。整个退款判断周期由官方根据工单审核结果决定，购买前需要做好心理预期。

**Q4：能试用吗？**

合规专线类产品一般没有无条件试用，新客专享也通常是限时价形式。建议第一次下单从 1TB / 月付档位试水，确认自己用得上、合规、延迟符合预期之后，再考虑季付或年付。
